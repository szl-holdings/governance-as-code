# Delaware C-Corp checklist (COM-016, COM-018)

Status column: ☐ open · ◐ in progress · ☑ done. Fill dates as each lands.

1. ☐ Confirm entity status: Delaware C-Corp in good standing (franchise tax
   paid, registered agent active). If not yet incorporated: file certificate
   of incorporation (standard startup set — Stripe Atlas / Clerky / counsel).
2. ☐ EIN issued and matched to legal name used on all contracts.
3. ☐ Bylaws adopted; board of directors constituted (solo founder = sole
   director initially).
4. ☐ 83(b)-aware founder stock issuance documented (if not already done at
   formation, flag immediately for counsel — 30-day windows are unforgiving).
5. ☐ Cap table export from source of truth (Carta or counsel-maintained
   spreadsheet): founders, option pool, SAFEs/notes outstanding, fully
   diluted totals. This is COM-016.
6. ☐ All contributor IP assignments executed
   (see IP_ASSIGNMENT_TEMPLATE.md; COM-017).
7. ☐ Any contractor agreements carry IP assignment clauses.
8. ☐ Open-source outbound licenses confirmed intentional (Apache-2.0 on
   repos verified in MODEL_BOM pass).
9. ☐ Conflicts check: NDA-bound external programs (e.g. red-team work)
   confirmed non-conflicting with Company IP claims.
10. ☐ Registered office + foreign qualification in NY (operating state).
